# Third-party notice collection

`Collect-Notices.ps1` produces `target/windows-notices/THIRD_PARTY_NOTICES.txt` from notices committed in this repository, supplied dependency-prefix copyright files, and optional supplemental documents. Packaging selects that generated file by default when present; explicit `NoticesDirectory` remains authoritative.

```powershell
.\platforms\windows\Collect-Notices.ps1 -DependencyPrefixes C:\deps\x64,C:\deps\x86 -SupplementalNotices C:\release\rust-frontend-notices.txt
```

The Rust crates statically linked into the host DLL and the settings binary are not in any dependency prefix. `cargo-about` or an equivalent Cargo-graph collector must produce that list, including the input engine `msime-engine` and `msime-path-trust` (this project's own crates under MPL-2.0 rather than GPL-3.0-only). Pass the result as a supplemental notice. The other workspace members are the project's GPL-3.0 code under the installer's `LICENSE.txt`.

The repository notices are read from where the data and code they cover are committed: `resources/licenses/msime-engine-dictionary-NOTICE.md` for the dictionary data, `resources/licenses/pinyin-data-MIT.txt`, `resources/licenses/ECDICT-MIT.txt`, `resources/licenses/rime_kaomoji_dict-MIT.txt` and `resources/licenses/python-pinyin-MIT.txt` for the MIT data in the installed dictionaries (the single-character readings of `msime-pinyin.db`, the English–Chinese glosses of `msime-english.db`, and the kaomoji and keyword phrase readings of `msime-others.db`), whose licences require the text in every copy; `resources/licenses/rime-wanxiang-CC-BY-4.0.txt` for the ranking weights `msime-pinyin.db` shares with rime-wanxiang, adapted from it under CC BY 4.0 (the attribution, the list of changes and the licence text); `resources/licenses/Administrative-divisions-of-China-WTFPL.txt` for the place names `@` mode offers; `resources/licenses/librime-octagram-BSD-3-Clause.txt` for the octagram reader the engine ports from librime-octagram, with the darts-clone (BSD-2-Clause) terms of its double-array layout appended; `resources/licenses/libcxx-Apache-2.0-WITH-LLVM-exception.txt` for the beam sorts the engine reproduces from libc++; `resources/licenses/kfcd-chaizi-CC-BY-3.0.txt` for the component reverse lookup table of 拆字反查 (C mode) compiled into the host library, adapted from kfcd/chaizi (CC BY 3.0, whose attribution and list of changes travel with it); `resources/licenses/Unicode-License-V3.txt` for the Unihan readings, ranks and traditional variants in that table and for the Unicode Character Database data the symbol mode (S mode) table compiled into the host library is chosen from; `resources/licenses/sentence-model-Apache-2.0.txt` for the rerank models; `resources/helpcodes/ENGINE-NOTICE.md`, `resources/helpcodes/NOTICE.md` and `resources/helpcodes/NOTICE-wubi86.md` for the helpcode tables; `platforms/windows/msimeui/UPSTREAM.md` and `platforms/windows/msimeui/LICENSE` for the candidate-window image decoder; the OpenCC licence compiled into the host library; `resources/licenses/onnxruntime-MIT.txt` and `resources/licenses/onnxruntime-ThirdPartyNotices.txt` for ONNX Runtime; and `resources/licenses/rerank-model-Apache-2.0.txt` for the keystroke rerank models. `-Edition` (default `full`) names the edition whose installer the notices go into and must have a Windows section in `shared/contracts/editions.json`. Each dependency prefix must provide at least one nonempty `share/<package>/copyright`; all such files are collected in sorted order with their SHA-256 and relative provenance. Supplemental files also carry hashes. Absolute local paths are not included. All inputs are read before an existing generated bundle is replaced, so missing inputs preserve prior output.

This is a collection tool, not a completeness or redistribution approval check. It does not infer which ports/crates were linked, fetch licenses, collect nested third-party archive licenses automatically, or grant permissions missing from upstream. The helpcode notices explicitly record unresolved redistribution permissions, and their original text is retained. Supply and review the nested archive, Rust, model and distribution-specific material; retain the application LICENSE. Missing records must not be papered over with a claim that the whole bundle has one license. Generated output is a release artifact, not a source-tree edit.
